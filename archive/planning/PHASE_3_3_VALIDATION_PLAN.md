# Phase 3.3: Test-Driven XSD Generation Implementation

## Goal

Generate XSD files from LUR + ShapeChange config that **exactly match** the reference XSD files in the LXR package (which were generated by ShapeChange).

## Reference Files (Gold Standard)

**Source**: `packages/plateau_schemas.lxr`

This LXR package contains the ShapeChange-generated XSD files. These are our target.

**Access via**: `lutaml-xsd` gem can extract XSD content from LXR packages

**Key XSD Files in LXR**:
- URO (urbanObject.xsd) - 255 classes
- URF (urbanFunction.xsd) - Urban planning package
- Plus imported schemas (GML, CityGML, core, etc.)

## Test-Driven Approach

### Step 1: Create Validation Spec

**File**: `spec/integration/xsd_shapechange_parity_spec.rb`

```ruby
RSpec.describe "XSD Generation ShapeChange Parity" do
  it "generates URO XSD matching ShapeChange output" do
    # 1. Load reference XSD from LXR
    lxr_adapter = SchemaRepositoryAdapter.new('packages/plateau_schemas.lxr')
    reference_xsd = lxr_adapter.repository.schemas.find { |s| s.namespace.include?('uro') }

    # 2. Generate XSD from LUR + config
    generated_xsd = generate_from_lur('uro')

    # 3. Compare structures
    expect(generated_xsd).to have_same_elements_as(reference_xsd)
    expect(generated_xsd).to have_same_types_as(reference_xsd)
    expect(generated_xsd).to have_same_namespaces_as(reference_xsd)
  end
end
```
