= Lutaml-Klin Examples

This document provides concrete examples of using Lutaml-Klin with the PLATEAU
URO (Urban Object) package, showing both YAML mapping outputs and human-readable
transformation reports.

== Example 1: Generating YAML Mappings

[source,shell]
----

  --config /path/to/ShapeChangeConfig_Plateau_uro.xml \
  --output uro-mappings.yaml \
  --verbose

== Example 3: Merging Multiple Mappings

=== Scenario

You have three separate mapping files for different PLATEAU packages:

* `uro-mappings.yaml` (Urban Object package)
* `bldg-mappings.yaml` (Building package)
* `tran-mappings.yaml` (Transportation package)

=== Command

[source,shell]
----
lutaml-klin merge \
  --inputs uro-mappings.yaml,bldg-mappings.yaml,tran-mappings.yaml \
  --output complete-plateau-mappings.yaml \
  --verbose
----

=== Output Structure

[source,yaml]
----

    class_mappings:

== Example 4: Programmatic Usage in Ruby

=== Loading and Querying Mappings

[source,ruby]
----
require 'lutaml/klin'

# Load the generated mapping
mapping = Lutaml::Klin::Models::Mapping::SchemaMapping.from_yaml(
  File.read('uro-mappings.yaml')
)

# Find a specific package
uro_package = mapping.package_mappings.find { |pkg| pkg.name == 'uro' }

puts "Package: #{uro_package.name}"
puts "Namespace: #{uro_package.namespace}"
puts "Number of classes: #{uro_package.class_mappings.size}"

# Find a specific class mapping
building = uro_package.class_mappings.find do |cls|
  cls.uml_class.name == 'Building'
end

puts "\nBuilding class mapping:"
puts "  UML name: #{building.uml_class.name}"
puts "  UML stereotype: #{building.uml_class.stereotype}"
puts "  XSD element: #{building.xsd_element&.name}"
puts "  XSD type: #{building.xsd_complex_type&.name}"

# Iterate through attributes
puts "\nAttribute mappings:"
building.attribute_mappings.each do |attr_map|
  uml_attr = attr_map.uml_attribute
  xsd_elem = attr_map.xsd_element

  puts "  #{uml_attr.name} (#{uml_attr.type}) → " \
       "#{xsd_elem.name} (#{xsd_elem.type})"
end

# Find all FeatureType classes
feature_types = uro_package.class_mappings.select do |cls|
  cls.uml_class.stereotype == 'FeatureType'
end

puts "\nFeatureType classes (#{feature_types.size}):"
feature_types.each do |cls|
  puts "  - #{cls.uml_class.name}"
end
----

== Example 5: Type Mapping Analysis

=== Finding All Type Conversions

[source,ruby]
----
require 'lutaml/klin'

mapping = Lutaml::Klin::Models::Mapping::SchemaMapping.from_yaml(
  File.read('uro-mappings.yaml')
)

# Collect all unique type conversions
type_conversions = {}

mapping.package_mappings.each do |package|
  package.class_mappings.each do |class_mapping|
    class_mapping.attribute_mappings.each do |attr_mapping|
      uml_type = attr_mapping.uml_attribute.type
      xsd_type = attr_mapping.xsd_element.type

      type_conversions[uml_type] ||= []
      type_conversions[uml_type] << xsd_type unless type_conversions[uml_type].include?(xsd_type)
    end
  end
end

# Display results
puts "UML Type → XSD Type Conversions:"
puts "=" * 50
type_conversions.sort.each do |uml_type, xsd_types|
  puts "#{uml_type}:"
  xsd_types.each do |xsd_type|
    puts "  → #{xsd_type}"
  end
end
----

== Example 8: Statistics and Metrics

=== Generating Mapping Statistics

[source,ruby]
----
require 'lutaml/klin'

mapping = Lutaml::Klin::Models::Mapping::SchemaMapping.from_yaml(
  File.read('uro-mappings.yaml')
)

# Calculate statistics
stats = {
  packages: mapping.package_mappings.size,
  classes: 0,
  attributes: 0,
  associations: 0,
  stereotypes: Hash.new(0)
}

mapping.package_mappings.each do |package|
  stats[:classes] += package.class_mappings.size

  package.class_mappings.each do |class_mapping|
    stats[:attributes] += class_mapping.attribute_mappings.size
    stats[:associations] += class_mapping.uml_class.associations.size
    stats[:stereotypes][class_mapping.uml_class.stereotype] += 1
  end
end

# Display results
puts "Mapping Statistics for PLATEAU URO"
puts "=" * 50
puts "Packages: #{stats[:packages]}"
puts "Classes: #{stats[:classes]}"
puts "Attributes: #{stats[:attributes]}"
puts "Associations: #{stats[:associations]}"
puts "\nClasses by Stereotype:"
stats[:stereotypes].sort_by { |_, count| -count }.each do |stereotype, count|
  puts "  #{stereotype}: #{count}"
end
----
