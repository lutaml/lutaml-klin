LutaML Klin is a tool in the LutaML modelling environment that allows
users to work across lutaml model types.

Features:

* Take a LutaML UML Repository (LUR) with a ShapeChange configuration
  and generate a XSD schema with a UML<->XSD mapping from it.

* Take a LUR and an LXR (LutaML XML Repository), and a mapping
  configuration, and generate a single-page interactive HTML site
  for exploring the mappings.
