## What's This?

This is a demonstration of the **Alpine.js-based Single Page Application (SPA)** for browsing UML-to-XSD mappings generated by lutaml-klin.

The Alpine.js template provides a modern, reactive user interface that makes it easy to explore complex UML-to-XSD transformations with real-time search, filtering, and interactive navigation.

## Comparison with Vanilla JS

The Alpine.js template is the **recommended default** for new SPAs. However, you can also generate the vanilla JavaScript version if needed.

### Generate Vanilla JS Version

```bash
cd ../..  # Back to project root
bundle exec ruby demo/generate_alpine_spa_demo.rb --vanilla
```

### Key Differences

| Feature | Alpine.js | Vanilla JS |
|---------|-----------|------------|
| **Code Size** | ~300 lines | ~700 lines |
| **Approach** | Declarative | Imperative |
| **Reactivity** | Automatic | Manual |
| **DOM Updates** | Automatic | Manual |
| **Dependencies** | Alpine.js CDN | None |
| **Maintainability** | Easier | More effort |
| **Browser Support** | Modern browsers | All browsers |

**When to use Alpine.js:**
- Default choice for new SPAs
- Want modern reactive patterns
- Prefer declarative code
- Team comfortable with Alpine.js

**When to use Vanilla JS:**
- External dependencies not allowed
- Maximum browser compatibility needed
- Team prefers traditional JavaScript
- Integration with existing vanilla JS code

## Troubleshooting

### Q: Search not working?
**A:** Check browser console for errors. Ensure Alpine.js CDN is accessible. If offline, you may need to bundle Alpine.js locally.

### Q: Styles look broken?
**A:** Ensure `assets/css/style.css` file exists in the spa directory. Check browser console for 404 errors.

### Q: No data displays?
**A:** Check that embedded data exists in the `<script id="embedded-data">` tag in index.html. View page source to verify.

### Q: Package tree not expanding?
**A:** This is a JavaScript issue. Check browser console for errors. Ensure Alpine.js loaded correctly.

### Q: Console shows Alpine errors?
**A:** Ensure Alpine.js CDN is reachable. Check your network connection. Consider using a local Alpine.js copy.

### Q: Mobile layout looks wrong?
**A:** Clear browser cache. Ensure viewport meta tag present. Try a hard refresh (Ctrl/Cmd + Shift + R).
