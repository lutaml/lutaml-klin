=== lutaml-xsd Capabilities ✅ AVAILABLE

==== LXR Package Creation
```bash
# Create LXR package from XSD files
lutaml-xsd package build config.yaml \
  --xsd-mode include_all \
  --resolution-mode resolved \
  --serialization-format marshal \
  --output schemas.lxr
```

==== SchemaRepository API
```ruby
# Load LXR package (instant loading)
repo = Lutaml::Xsd::SchemaRepository.from_package('schemas.lxr')

# Type resolution (compatible with lutaml-klin)
result = repo.find_type('gml:CodeType')
# Returns: resolved?, local_name, namespace, schema_file, resolution_path
```

==== Package Configuration
* **XSD Mode**: `include_all` (self-contained) vs `allow_external`
* **Resolution Mode**: `resolved` (pre-serialized) vs `bare` (parse on load)
* **Serialization**: `marshal` (fastest), `json` (portable), `yaml` (readable)
