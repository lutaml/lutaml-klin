= Rule: rule-xsd-prop-initialValue

== Overview

Adds `default` or `fixed` attribute to property elements based on the initialValue and readonly status of the property.

== Priority

Must-have (supports default and constant values in schemas)

== ShapeChange Documentation

Source:: `/Users/mulgogi/src/external/ShapeChange/shapechange-app/src/docs/asciidoc/targets/xml schema/General_Conversion_Rules.adoc`

Description::
Properties with initial values should have those values reflected in the XML Schema through `default` or `fixed` attributes, depending on whether the property is readonly.

== Java Implementation

Source:: [`XsdDocument.java:addProperty`](lines 2139-2150 and 2245-2250)

=== Algorithm

The Java implementation follows this process:

. Check if property has `initialValue()` that is not null/empty
. Check if property matches [`rule-xsd-prop-initialValue`]
. Strip quotes from the initial value
. Determine attribute type based on readonly status:
  * If `isReadOnly()` is true: Use `fixed` attribute
  * If `isReadOnly()` is false: Use `default` attribute
. For XML attributes with default: Remove `use` attribute (default implies optional)

=== Implementation Logic

[source,java]
----
if (pi.initialValue() != null && !pi.initialValue().isEmpty()
        && pi.matches("rule-xsd-prop-initialValue")) {
    if (pi.isReadOnly()) {
        addAttribute(e1, "fixed", stripQuotes(pi.initialValue()));
    } else {
        addAttribute(e1, "default", stripQuotes(pi.initialValue()));

        if (e1.hasAttribute("use")) {
            // if @default is present, the @use attribute must have
            // the value optional (default)
            e1.removeAttribute("use");
        }
    }
}
----

=== Design Principles

. Clear distinction between default (changeable) and fixed (readonly) values
. Quote stripping for cleaner XML output
. Proper handling of XML attribute use restrictions
. Configuration over code (reads from property metadata)

=== Implementation Details

The [`InitialValueProcessor`] class extends [`BaseRuleProcessor`] and:

. Checks if property has initialValue
. Determines if property is readonly
. Strips quotes from value string
. Adds appropriate attribute (default or fixed)
. Handles use attribute for XML attributes with defaults

== Notes

* `default` allows value to be changed in XML instances
* `fixed` makes the value immutable (constant)
* Quotes are stripped from the initial value string
* For XML attributes, `default` implies optional (use attribute removed)
* Initial values work with both elements and attributes
* Empty initial values are ignored (no default/fixed added)
