= Rule: rule-xsd-cls-adehook

== Overview

Generates abstract ADE (Application Domain Extension) hook elements that allow schema extensions without modifying the base schema.

== Priority

Must-have (generates hook elements for extension points)

== ShapeChange Documentation

Source:: `/Users/mulgogi/src/external/ShapeChange/shapechange-app/src/docs/asciidoc/targets/xml schema/General_Conversion_Rules.adoc`

Description::
ADE hooks are abstract elements that serve as extension points in GML application schemas, allowing additional properties to be added through substitution groups without modifying the original schema.

== Java Implementation

Source:: [`XsdDocument.java:processLocalProperties`](lines 1960-1981)

=== Algorithm

The Java implementation follows this process:

. Check if class matches [`rule-xsd-cls-adehook`]
. Construct element name: `"AbstractGenericApplicationPropertyOf" + ci.name()`
. Add property reference to the sequence/choice container:
  * Create `<element>` with ref to hook element
  * Set `minOccurs="0"` and `maxOccurs="unbounded"`
. Add global hook element definition:
  * Create `<element>` with constructed name
  * Set `type="anyType"`
  * Set `abstract="true"`
. Record in encoding infos if enabled

=== Implementation Logic

[source,java]
----
if (ci.matches("rule-xsd-cls-adehook")) {
    // Name of the ADE hook
    String elementName = "AbstractGenericApplicationPropertyOf" + ci.name();

    // add property
    Element e1 = document.createElementNS(Options.W3C_XML_SCHEMA, "element");
    addAttribute(e1, "ref", elementName);
    addMinMaxOccurs(e1, new Multiplicity("0..*"));
    sequenceOrChoice.appendChild(e1);

    // add element
    Element e4 = document.createElementNS(Options.W3C_XML_SCHEMA, "element");
    document.getDocumentElement().appendChild(e4);
    addAttribute(e4, "name", elementName);
    addAttribute(e4, "type", "anyType");
    addAttribute(e4, "abstract", "true");
}
----

=== Design Principles

. Enables schema extensibility without modification
. Clear naming convention for hook elements
. Abstract elements prevent direct instantiation
. Flexible extension through substitution groups

=== Implementation Details

The [`AdeHookProcessor`] class extends [`BaseRuleProcessor`] and:

. Constructs hook element name from class name
. Creates property reference with unbounded multiplicity
. Generates global abstract hook element
. Adds to encoding infos for documentation

== Test Cases

=== Test Case 1: Simple ADE Hook

Input UML::
[source]
----
«featureType» Building {adehook}
  property name: String [1]
  property height: Measure [1]
----

Expected XSD::
[source,xml]
----
<complexType name="BuildingType">
  <complexContent>
    <extension base="gml:AbstractFeatureType">
      <sequence>
        <element name="name" type="string"/>
        <element name="height" type="MeasureType"/>
        <element ref="AbstractGenericApplicationPropertyOfBuilding"
                 minOccurs="0" maxOccurs="unbounded"/>
      </sequence>
    </extension>
  </complexContent>
</complexType>

<element name="AbstractGenericApplicationPropertyOfBuilding"
         type="anyType" abstract="true"/>
----

== Notes

* Hook elements are always abstract (cannot be instantiated directly)
* Naming pattern: `AbstractGenericApplicationPropertyOf{ClassName}`
* Multiplicity is always `0..*` (optional, unbounded)
* Hook reference appears at end of property sequence
* Extensions use `substitutionGroup` to add custom properties
* Type is always `anyType` allowing any content
* Critical for CityGML and PLATEAU extensions
