= rule-xsd-prop-gmlArrayProperty

== Purpose

Creates GML array property types for properties with the `gmlArrayProperty` tagged value.

== Algorithm

1. Check if property has tagged value `gmlArrayProperty="true"`
2. Verify `inlineOrByReference` setting is "inline"
3. Generate anonymous array property type with:
   - Sequence element containing the target element reference
   - minOccurs set on the sequence based on property cardinality
   - Target element reference from element map entry

private boolean asArray(PropertyInfo propi) {
    boolean asArray = false;
    if (propi.matches("rule-xsd-prop-gmlArrayProperty")) {
        String s = propi.taggedValue("gmlArrayProperty");
        asArray = "true".equalsIgnoreCase(s);
    }
    if (asArray) {
        if (!propi.matches("rule-xsd-prop-inlineOrByReference") ||
            !propi.inlineOrByReference().equals("inline")) {
            asArray = false;
            // Error message
        }
    }
    return asArray;
}

== Constraints

* Property must have `inlineOrByReference="inline"`
* Type must have an element mapping
* Property cannot be in an association class context

== Example

Property with `gmlArrayProperty="true"` generates:

  <complexType>
    <sequence>
      <element ref="gml:AbstractFeature" minOccurs="0" maxOccurs="unbounded"/>
    </sequence>
