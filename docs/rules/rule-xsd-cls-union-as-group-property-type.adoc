= rule-xsd-cls-union-as-group-property-type

== Purpose

Encodes union types as XML Schema groups with choice semantics in property types.

This provides an alternative to standard property type encoding for unions.

== Applies To

* Union classes
* Properties with union types

== Algorithm

When this rule is enabled for a union class:

1. **Generate group**: Create `xs:group` with `xs:choice` for union properties
   ```xml
   <xs:group name="{UnionName}Group">
     <xs:choice>
       <!-- union option elements -->
     </xs:choice>
   </xs:group>
   ```

2. **Property type structure**: Include group reference in property type
   ```xml
   <xs:complexType name="{UnionName}PropertyType">
     <xs:sequence minOccurs="0">
       <xs:group ref="prefix:UnionGroup"/>
     </xs:sequence>
     <xs:attributeGroup ref="swe:AssociationAttributeGroup"/>
   </xs:complexType>
   ```

3. **For SWE Common**: Works with `rule-xsd-cls-standard-swe-property-types`

== Configuration

No additional parameters required beyond enabling the rule.

== Example Output

For a union with multiple options:
[source,xml]
----
<xs:group name="ValueGroup">
  <xs:choice>
    <xs:element ref="swe:Quantity"/>
    <xs:element ref="swe:Boolean"/>
    <xs:element ref="swe:Text"/>
  </xs:choice>
</xs:group>

<xs:complexType name="ValuePropertyType">
  <xs:sequence minOccurs="0">
    <xs:group ref="swe:ValueGroup"/>
  </xs:sequence>
  <xs:attributeGroup ref="swe:AssociationAttributeGroup"/>
</xs:complexType>
----

== Usage Pattern

Typically used when:
- Union represents value type choices
- Need group reusability across schema
- SWE Common encoding pattern preferred
- Choice semantics over union semantics

== Group Structure

The generated group:
1. Contains `xs:choice` element
2. Lists all union option elements as references
3. Can be referenced multiple times
4. Provides reusable choice pattern

== Use Cases

* **SWE Common values**: Value type unions in SWE
* **Polymorphic data**: Multiple data type options
* **Reusable choices**: Shared choice groups
* **Type flexibility**: Flexible property values

== Notes

- Creates both group and property type
- Property type includes sequence with group reference
- Works with SWE `AssociationAttributeGroup`
- Provides reusability through group references
- Part of SWE Common encoding patterns
