= rule-xsd-prop-targetElement

== General

The `rule-xsd-prop-targetElement` adds `<gml:targetElement>` annotations in appinfo sections for GML 3.2 association properties that are encoded by reference.

This rule provides explicit typing information for associations, enabling validation and semantic understanding of reference relationships.

== Purpose

Target element annotations serve to:

* Declare the expected type of referenced objects
* Support validation of xlink:href targets
* Enable tooling to understand association semantics
* Comply with GML 3.2 association metadata patterns

== Algorithm Steps

. Verify GML namespace is "http://www.opengis.net/gml/3.2"
. Check property encoding is "byreference" or OKSTRAFID class
. Verify value type is not a code list
. Verify value type has an object element representation
. Determine target element name (via map entry or qname)
. Create `<gml:targetElement>` element in appinfo
. Add element name as text content

== Implementation

The Ruby implementation:

[source,ruby]
----
def apply_rule(property, context)
  return unless gml_32?(context)
  return unless by_reference_or_okstra?(property, context)

  value_class = get_value_class(property, context)
  return unless value_class
  return if code_list?(value_class)
  return unless has_object_element?(value_class)

  target_element = determine_target_element(value_class, context)
  add_target_element_annotation(target_element, context)
end

def gml_32?(context)
  context[:gml_namespace] == "http://www.opengis.net/gml/3.2"
end

def by_reference_or_okstra?(property, context)
  encoding = get_encoding_mode(property)
  return true if encoding == "byreference"

  # Check OKSTRAFID with rule-xsd-cls-okstra-fid
  value_class = get_value_class(property, context)
  return false unless value_class

  value_class.category.to_s.upcase == "OKSTRAFID" &&
    applies_to?(value_class, "rule-xsd-cls-okstra-fid")
end

def add_target_element_annotation(target_element, context)
  appinfo = ensure_appinfo_element(context)

  # Create gml:targetElement
  target_elem = create_gml_element("targetElement", context)
  target_elem.content = target_element
  appinfo.add_child(target_elem)
end
----

== Usage Example

.Association with target element annotation
====
Given a property with `inlineOrByReference = "byreference"` to a Feature class:

[source,xml]
----
<xs:element name="relatedFeature" type="gml:ReferenceType">
  <xs:annotation>
    <xs:appinfo>
      <gml:targetElement>app:Building</gml:targetElement> <!--1-->
    </xs:appinfo>
  </xs:annotation>
</xs:element>
----
<1> Target element annotation specifying expected type
====
