= rule-xsd-prop-gmlListProperty

== Purpose

Creates XML Schema list-based simple types for properties with the `gmlListProperty` tagged value.

== Algorithm

1. Check if property has tagged value `gmlListProperty="true"`
2. Create `xs:list` with `itemType` from mapped type
3. Add `minLength`/`maxLength` restrictions based on cardinality:
   - If min=max: use `length` restriction
   - If min>0: use `minLength` restriction
   - If max<∞: use `maxLength` restriction

private boolean asList(PropertyInfo propi) {
    boolean asList = false;
    if (propi.matches("rule-xsd-prop-gmlListProperty")) {
        String s = propi.taggedValue("gmlListProperty");
        asList = "true".equalsIgnoreCase(s);
    }
    return asList;
}

== Constraints

* Property type must map to a simple type
* Not compatible with complex types

== Example

Property with `gmlListProperty="true"` and cardinality 2..5 generates:

[source,xml]
----
<element name="values">
  <simpleType>
    <restriction>
      <simpleType>
        <list itemType="xs:double"/>
      </simpleType>
      <minLength value="2"/>
      <maxLength value="5"/>
    </restriction>
  </simpleType>
</element>
