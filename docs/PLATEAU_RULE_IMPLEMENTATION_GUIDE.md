# PLATEAU Custom Rule: Implementation Guide

## Overview

This guide shows how to implement and use the PLATEAU custom encoding rule that generates the final XSD output with CityGML ADE hook elements (replicating the VBA post-processing in a single step).

## The Custom Rule Configuration

### File: `config/encoding_rules/plateau.yml`

```yaml
---
# PLATEAU Custom Encoding Rule
# Extends CityGML with PLATEAU-specific ADE hook elements

encoding_rule:
  name: plateau
  extends: citygml
  description: PLATEAU 3.2 encoding rule with CityGML ADE integration

  rules:
    # Include CityGML ADE hook element generation
    - rule-xsd-cls-plateau-ade-hooks

  # Mapping of URO/URF classes to CityGML base types
  # This data drives the PlateauAdeHooksProcessor
  citygml_extensions:
    # Building-related attributes (prefix: bldg)
    - class: DataQualityAttribute
      citygml_prefix: bldg
      citygml_base: AbstractBuilding

    - class: ConstructionBaseAttribute
      citygml_prefix: bldg
      citygml_base: AbstractBuilding

    - class: BuildingIDAttribute
      citygml_prefix: bldg
      citygml_base: AbstractBuilding

    # ... (all 99 mappings extracted from VBA analysis)

    # Transportation-related (prefix: tran)
    - class: TrafficVolumeAttribute
      citygml_prefix: tran
      citygml_base: Road

    # Land use-related (prefix: luse)
    - class: LandUse2DAttribute
      citygml_prefix: luse
      citygml_base: LandUse
```

**This YAML file is the complete VBA logic as configuration data!**

## Single-Step XSD Generation Command

### Basic Usage

```bash
# Generate PLATEAU XSD with ADE hooks (final output)
bundle exec exe/lutaml-klin xsd \
  --lur packages/plateau_all.lur \
  --config config/plateau_encoding_rule.xml \
  --config reference/shapechange-configs/ShapeChangeConfig_Plateau_Final.xml \
  --packages "uro,urf" \
  --output final_schemas/
```

### With All Options

```bash
# Complete command with validation
bundle exec exe/lutaml-klin xsd \
  --lur packages/plateau_all.lur \

  --verbose
```

## Validation

### Test That Proves 100% Match

```ruby
# spec/integration/plateau_final_xsd_spec.rb
RSpec.describe "PLATEAU Final XSD Generation" do
  it "generates XSD matching published PLATEAU schemas exactly" do
    # Generate with PLATEAU rule
    results = generate_with_encoding_rule('plateau', ['uro', 'urf'])

    # Load published XSD from iur repository
    published_uro = load_xsd_from_lxr('packages/plateau_schemas.lxr', 'uro')
    generated_uro = parse_xsd(results.find { |r| r[:package] == 'uro' }[:file])

    # Compare
    expect(generated_uro.elements.count).to eq(published_uro.elements.count)
    expect(generated_uro.types.count).to eq(published_uro.types.count)

    # Check ADE hooks specifically
    ade_hooks = generated_uro.elements.select { |e| e.substitution_group&.include?('_GenericApplicationPropertyOf') }
    expect(ade_hooks.count).to eq(99)  # All VBA modifications present!

    # Should be 100% match!
  end
end
```
