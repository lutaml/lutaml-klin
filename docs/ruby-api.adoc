= Ruby API

== Purpose

This document provides a comprehensive reference for using Lutaml-Klin
programmatically in Ruby applications.

Use this guide to:

* Load and query UML-to-XSD mappings in your Ruby code
* Build custom tools and workflows on top of Lutaml-Klin
* Integrate Lutaml-Klin into larger Ruby applications
* Extend Lutaml-Klin with custom functionality

== Concepts

=== Lutaml::Model serialization

All Lutaml-Klin models inherit from `Lutaml::Model::Serializable`, providing:

* **Automatic serialization** to YAML, JSON, and XML
* **Type-safe deserialization** from these formats
* **Validation** of required fields
* **Structured access** to nested data

Example:

[source,ruby]
----
# Load from YAML
mapping = SchemaMapping.from_yaml(File.read('mapping.yaml'))

# Access data
puts mapping.package_mappings.first.name

# Convert to JSON
json = mapping.to_json

# Save as XML
File.write('mapping.xml', mapping.to_xml)
----

=== Model object hierarchy

Lutaml-Klin provides a complete object model for UML-XSD mappings:

[source]
----
SchemaMapping              # Root container
├── PackageMapping[]       # UML packages
│   └── ClassMapping[]     # UML classes
│       └── AttributeMapping[]  # UML attributes
├── UmlClass               # UML class definitions
│   ├── Attribute[]        # UML attributes
│   └── Association[]      # UML associations
├── ElementMapping         # XSD elements
└── ComplexTypeMapping     # XSD complex types
----

All models are immutable after creation (no setters after initialization).

=== Programmatic access patterns

Common patterns for working with mappings:

* **Loading**: Deserialize from YAML/JSON
* **Querying**: Filter and search mappings
* **Transforming**: Generate custom outputs
* **Analyzing**: Compute statistics and metrics

== Core API

=== XmiNavigator

Parse XMI files and extract UML models.

==== Creating a navigator

[source,ruby]
----
require 'lutaml/klin'

navigator = Lutaml::Klin::XmiNavigator.new
----

==== Parsing XMI files

[source,ruby]
----
# Parse an XMI file
navigator.parse_file('/path/to/model.xmi')

# Or parse from string
xmi_content = File.read('/path/to/model.xmi')
navigator.parse(xmi_content)
----

==== Accessing packages

[source,ruby]
----
# Get all packages
packages = navigator.packages
# => Array<Lutaml::Klin::Models::Uml::Package>

puts "Found #{packages.size} package(s)"

# Find a specific package by name
uro_package = navigator.find_package('uro')
# => Lutaml::Klin::Models::Uml::Package or nil

if uro_package
  puts "Package: #{uro_package.name}"
  puts "Namespace: #{uro_package.namespace}"
  puts "ID: #{uro_package.id}"
end
----

==== Accessing classes

[source,ruby]
----
# Get all classes in a package
classes = navigator.classes_in_package('uro')
# => Array<Lutaml::Klin::Models::Uml::Class>

puts "Found #{classes.size} class(es)"

# Iterate through classes
classes.each do |cls|
  puts "Class: #{cls.name}"
  puts "  Stereotype: #{cls.stereotype}"
  puts "  Attributes: #{cls.attributes.size}"
  puts "  Associations: #{cls.associations.size}"
end
----

==== Complete example

[source,ruby]
----
require 'lutaml/klin'

# Parse XMI
navigator = Lutaml::Klin::XmiNavigator.new
navigator.parse_file('plateau-uro.xmi')

# Get package
package = navigator.find_package('uro')

# Get classes
classes = navigator.classes_in_package('uro')

# Find FeatureType classes
feature_types = classes.select do |cls|
  cls.stereotype == 'FeatureType'
end

puts "FeatureType classes in URO package:"
feature_types.each do |cls|
  puts "  - #{cls.name}"

  # Show attributes
  cls.attributes.each do |attr|
    puts "    * #{attr.name}: #{attr.type} [#{attr.multiplicity_min}..#{attr.multiplicity_max}]"
  end
end
----

== Statistics and metrics

=== Computing mapping statistics

[source,ruby]
----
require 'lutaml/klin'

mapping = Lutaml::Klin::Models::Mapping::SchemaMapping.from_yaml(
  File.read('mapping.yaml')
)

# Initialize counters
stats = {
  packages: 0,
  classes: 0,
  attributes: 0,
  associations: 0,
  resolved: 0,
  unresolved: 0,
  stereotypes: Hash.new(0)
}

# Collect statistics
mapping.package_mappings.each do |pkg|
  stats[:packages] += 1

  pkg.class_mappings.each do |cls|
    stats[:classes] += 1
    stats[:stereotypes][cls.uml_class.stereotype] += 1
    stats[:associations] += cls.uml_class.associations.size

    cls.attribute_mappings.each do |attr_map|
      stats[:attributes] += 1

      if attr_map.resolution_status == :resolved
        stats[:resolved] += 1
      else
        stats[:unresolved] += 1
      end
    end
  end
end

# Display statistics
puts "Mapping Statistics:"
puts "  Packages: #{stats[:packages]}"
puts "  Classes: #{stats[:classes]}"
puts "  Attributes: #{stats[:attributes]}"
puts "  Associations: #{stats[:associations]}"
puts "  Resolved types: #{stats[:resolved]}"
puts "  Unresolved types: #{stats[:unresolved]}"
puts "\nClasses by stereotype:"
stats[:stereotypes].sort_by { |_, count| -count }.each do |stereotype, count|
  puts "  #{stereotype}: #{count}"
end
----

=== Analyzing type conversions

[source,ruby]

# Collect all type conversions
conversions = Hash.new { |h, k| h[k] = [] }

== Integration examples

=== Using with lutaml-xsd (future)

[source,ruby]
----
require 'lutaml/klin'
require 'lutaml/xsd'

# Generate mapping
mapping = Lutaml::Klin::MappingGenerator.new.generate(
  'model.xmi',
  'config.xml'
)

# Create schema repository
repo = Lutaml::Xsd::SchemaRepository.new
repo.load_namespace_config(config.xml_namespaces)
repo.load_schema_directory('/path/to/xsd/schemas')

# Resolve unresolved types
mapping.package_mappings.each do |pkg|
  pkg.class_mappings.each do |cls|
    cls.attribute_mappings.each do |attr|
      next if attr.resolution_status == :resolved

      # Parse namespaced type (e.g., "gml:CodeType")
      if attr.uml_attribute.type =~ /^(\w+):(\w+)$/
        prefix, local_name = $1, $2

        # Resolve type
        resolved = repo.resolve_type(
          prefix: prefix,
          type_name: local_name
        )

        if resolved
          attr.xsd_element.type = local_name
          attr.xsd_element.namespace = resolved.namespace
          attr.resolution_status = :resolved
        end
      end
    end
  end
end

# Save updated mapping
File.write('mapping-resolved.yaml', mapping.to_yaml)

=== Building a validation tool

[source,ruby]
----
require 'lutaml/klin'

class MappingValidator
  def initialize(mapping_path, xsd_path)
    @mapping = SchemaMapping.from_yaml(File.read(mapping_path))
    @xsd_path = xsd_path
  end

  def validate
    errors = []
    warnings = []

    @mapping.package_mappings.each do |pkg|
      pkg.class_mappings.each do |cls|
        # Check for missing XSD mapping
        unless cls.xsd_element
          errors << "Class #{cls.uml_class.name} has no XSD element"
        end

        # Check for unresolved types
        cls.attribute_mappings.each do |attr|
          if attr.resolution_status == :unresolved
            warnings << "#{cls.uml_class.name}.#{attr.uml_attribute.name}: " \
                        "unresolved type #{attr.uml_attribute.type}"
          end
        end
      end
    end

    {
      valid: errors.empty?,
      errors: errors,
      warnings: warnings
    }
  end
end

# Use validator
validator = MappingValidator.new('mapping.yaml', '/path/to/xsd')
result = validator.validate

if result[:valid]
  puts "✓ Mapping is valid"
else
  puts "✗ Mapping has errors:"
  result[:errors].each { |e| puts "  - #{e}" }
end

if result[:warnings].any?
  puts "⚠ Warnings:"
  result[:warnings].each { |w| puts "  - #{w}" }
end

=== Building a diff tool

[source,ruby]
----
require 'lutaml/klin'

class MappingDiff
  def initialize(old_path, new_path)
    @old = SchemaMapping.from_yaml(File.read(old_path))
    @new = SchemaMapping.from_yaml(File.read(new_path))
  end

  def diff
    changes = {
      added_classes: [],
      removed_classes: [],
      modified_classes: []
    }

    old_classes = collect_classes(@old)
    new_classes = collect_classes(@new)

    # Find added classes
    new_classes.each do |name, cls|
      unless old_classes[name]
        changes[:added_classes] << name
      end
    end

    # Find removed classes
    old_classes.each do |name, cls|
      unless new_classes[name]
        changes[:removed_classes] << name
      end
    end

    # Find modified classes
    old_classes.each do |name, old_cls|
      if new_classes[name]
        new_cls = new_classes[name]
        if classes_differ?(old_cls, new_cls)
          changes[:modified_classes] << name
        end
      end
    end

    changes
  end

  private

  def collect_classes(mapping)
    classes = {}
    mapping.package_mappings.each do |pkg|
      pkg.class_mappings.each do |cls|
        classes[cls.uml_class.name] = cls
      end
    end
    classes
  end

  def classes_differ?(old_cls, new_cls)
    # Compare attribute counts
    old_cls.attribute_mappings.size != new_cls.attribute_mappings.size
  end
end

# Use diff tool
diff = MappingDiff.new('old-mapping.yaml', 'new-mapping.yaml')
changes = diff.diff

puts "Changes:"
puts "  Added: #{changes[:added_classes].size}"
puts "  Removed: #{changes[:removed_classes].size}"
puts "  Modified: #{changes[:modified_classes].size}"
----

def validate_mapping(mapping)
  errors = []

  if mapping.package_mappings.empty?
    errors << "No package mappings found"
  end

  mapping.package_mappings.each do |pkg|
    if pkg.name.nil? || pkg.name.empty?
      errors << "Package has no name"
    end

    if pkg.class_mappings.empty?
      errors << "Package #{pkg.name} has no classes"
    end
  end

  errors
end

errors = validate_mapping(mapping)
if errors.any?
  puts "Validation errors:"
  errors.each { |e| puts "  - #{e}" }
  exit 1

== Best practices

=== Use specific queries

Instead of:

[source,ruby]
----
# Bad: Iterate everything
all_classes = []
mapping.package_mappings.each do |pkg|
  pkg.class_mappings.each do |cls|
    all_classes << cls
  end
end
----

Do:

[source,ruby]
----
# Good: Use targeted queries
def find_classes(mapping, &block)
  mapping.package_mappings.flat_map do |pkg|
    pkg.class_mappings.select(&block)
  end
end

feature_types = find_classes(mapping) do |cls|
  cls.uml_class.stereotype == 'FeatureType'
end

=== Cache expensive operations

[source,ruby]
----
class MappingAnalyzer
  def initialize(mapping)
    @mapping = mapping
    @class_index = nil
  end

  def class_index
    @class_index ||= build_class_index
  end

  private

  def build_class_index
    index = {}
    @mapping.package_mappings.each do |pkg|
      pkg.class_mappings.each do |cls|
        index[cls.uml_class.name] = cls
      end
    end
    index
  end
end
----
